# Module 04 — Appeler un LLM (S12, 8–14 févr.)

Ressources : [documentation Mistral](https://docs.mistral.ai), [Ollama](https://ollama.com) (modèle local gratuit).

## Avant de commencer
1. Crée ta clé API (plan gratuit Mistral : pas de carte bancaire, vérification par téléphone).
2. Copie `.env.example` (à la racine) en `.env` et mets-y ta clé.
3. Vérifie avec `git status` que `.env` n'apparaît pas.
4. `pip install mistralai python-dotenv`

Le plan gratuit peut utiliser tes requêtes pour entraîner les modèles : n'envoie pas de données personnelles.
