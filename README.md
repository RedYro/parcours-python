# Parcours Python → Développeur IA

Parcours d'apprentissage de Python, commencé en novembre 2026, pour préparer l'alternance **Développeur en intelligence artificielle** (RNCP 37827) qui démarre en avril 2027.

Titulaire du titre professionnel **Développeur Web et Web Mobile** (RNCP 31114), je m'appuie sur mes bases en HTML, CSS, JavaScript et PHP pour apprendre Python, puis les API, puis l'IA.
